# 🛡️ سوئیت «یار» — نگهبان‌یار، مدیر یار، ساکن‌یار

سامانهٔ مدیریت نگهبانی ساختمان‌های مسکونی: سه اپ بومی اندروید + هاب چندساختمانی + پنل وب + ربات پشتیبانی بله.

> توسعهٔ سورس در مخزن خصوصی انجام می‌شود؛ این مخزن فقط برای **انتشار نسخه‌ها، صفحهٔ محصول و ربات بله** است.

## ✨ امکانات

- **گشت QR ضدتقلب:** اسکن کاملاً آفلاین پلاک‌ها با امضای HMAC، قرعهٔ تصادفی ساعت و مسیر گشت، چالش بیداری نگهبان
- **بدون وقفه در ایران:** آپدیت خودکار از سه مسیر (گیت‌هاب ← صفحهٔ محصول ← سرور) با گیت اجباری نصب نسخهٔ جدید
- **چرخهٔ درخواست:** ساکن درخواست می‌دهد ← مدیر تأیید/رد می‌کند ← نگهبان با اعلان مطلع می‌شود
- **گزارش و پشتیبانی در بله:** گزارش صبح گشت، ثبت مهمان و بسته (با پیامک خودکار)، ربات پشتیبانی با ضمیمهٔ خودکار خطاها
